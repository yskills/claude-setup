# Own desktop per thread (2026-10-08)

Question: can every Claude thread get its own screen (apps, browser, test its work, yskills watches)?

## Answer

Yes, in two halves:

1. **Own screen + recording: works today, free.** Every cloud container has Xvfb, ffmpeg and
   Chromium. Proof run in this thread: a headed Chromium on virtual display `:99`, typed into a
   page, recorded to WebM (frame checked). Shipped as `ui-review/scripts/desktop.sh` (claude-setup).
   Web flows can use Playwright's built-in `video: 'on'` instead.
2. **Watching live from the phone: not free.** Cloud containers take no inbound connections, so a
   live view needs either a tunnel out of the container or a hosted sandbox that gives a viewer URL.

## Options for live view

| Option | What it is | Cost | Verdict |
|---|---|---|---|
| Recorded WebM per test run (shipped) | thread records, attaches video | 0 € | default |
| Laptop computer use (already works) | thread drives yskills' real Windows desktop | 0 € | same screen yskills uses; one thread at a time; laptop must be on |
| E2B Desktop | Ubuntu + XFCE sandbox, `streamUrl()` gives a password noVNC link, view-only option | Hobby 0 €/month + ~0.06 €/h per vCPU, 100 $ one-time credits, 1 h sessions; Pro ~140 €/month (150 $) for 24 h | best live option; needs an API key and a new service |
| Browserbase | hosted browsers with Live View | Free 1 browser-hour; Developer ~19 €/month (20 $) | browser only, not a full desktop |
| Tunnel from container (cloudflared quick tunnel + noVNC) | expose the container's screen | 0 € | new service, a public URL to the container, may be blocked by the proxy; not recommended |
| Remote Control "Use worktrees" (laptop setting) | each RC thread gets its own git worktree | 0 € | isolates files, not screens; turn on so parallel PC threads never clash |
| Windows Sandbox / Hyper-V on laptop | separate Windows desktop per thread | 0 € | needs Windows 11 Pro (edition unverified), 16 GB RAM fits one or two; laptop must stay on |
| Docker desktop container on laptop | Linux desktop with noVNC | 0 € | needs Docker Desktop installed (TALK FIRST) |

## Recommendation

Keep the free recorded-video way as default (shipped). Add E2B only if yskills wants to watch
live from the phone; at our volume (a few test runs a day) the 100 $ credits last months.
Agrees with the PC thread: a rented always-on VM isn't worth it yet.

Sources: e2b.dev/pricing, e2b.dev/docs/use-cases/computer-use, Capterra Browserbase pricing,
tinyfish.ai/blog/browserbase-pricing.
