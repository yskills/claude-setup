# Moves

Shared animations for every VRM character: one file plays on all of them, because VRM bodies share one skeleton.
Put `.vrma` files here (VRM Animation; three-vrm plays them with `@pixiv/three-vrm-animation`), each with a row in
`../manifest.json`. Mixamo FBX also works, retargeted at load (three-vrm's `loadMixamoAnimation` example).
Free sources with a game-safe licence: Quaternius Universal Animation Library (CC0), VRoid's own VRMA samples
(check the licence on the download page). None are stored yet: HQ's figures walk and type with code-driven poses.
